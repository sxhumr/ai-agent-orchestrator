# ForgeFlow backend

The Python package: Claude Code runtime adapter, requirements analysis, SQLite store, the `forgeflow` CLI and the loopback FastAPI app the frontend talks to.

```bash
uv sync
uv run forgeflow serve        # API on http://127.0.0.1:8765
uv run pytest tests/unit
```

See the [project README](../README.md) for the full guide.
